\section{AI-tool use statement}\label{sec:aiuse}

\paragraph{Tool.} The project used Claude Code~\citep{claudecode}, Anthropic's agentic coding tool, with the Claude Opus 5.5 model. It ran on the student's laptop with passwordless SSH to Explorer, as one orchestrator plus four worker sub-agents (repro, improve, analysis, report) briefed in writing, and a fresh-context reviewer at the end.
The AI is credited as a tool, not as an author. The student is responsible for the report and the repository.

\paragraph{What the agent did.}
\begin{itemize}[leftmargin=*]
  \item planned in plan mode, then executed the approved plan;
  \item wrote the code: data scripts, Slurm jobs, configs, the evaluator, tests and statistics, demos, figure and table generators, and this report's source;
  \item submitted and monitored jobs, and diagnosed their failures;
  \item audited the upstream code and data;
  \item verified the literature;
  \item kept \code{SKILL.md}, \code{AGENT.md}, \code{MANIFEST.md} and the notebooks current.
\end{itemize}

\paragraph{What the human did.}
\begin{itemize}[leftmargin=*]
  \item set the goal and constraints (the rubric and the course rules);
  \item required and approved a plan;
  \item supplied the course slides and guide;
  \item asked for parallel agents;
  \item set the secrets and no-co-author policies;
  \item reviewed results and documents.
\end{itemize}

\paragraph{How outputs were verified.}
\begin{enumerate}[label=(\arabic*), leftmargin=*]
  \item \res{tests.n} unit tests, run locally and on the cluster.
  \item Agreement with upstream's printed AP on \res{xcheck.pairs} run/split pairs.
  \item SHA256 for every download and checkpoint, plus a \code{run.json} provenance record per run.
  \item Script-enforced pre-registration.
  \item No hand-typed results: every number comes from \code{report/generated/}. Numbers without a generated key sit in \code{manual_numbers.tex} with their source, mirrored in \code{results/tables/provenance.csv}.
  \item Online verification of every reference (\code{report/check_bib.py}).
  \item A fresh-context final review.
\end{enumerate}

\paragraph{Agent errors caught by these checks.}
\begin{itemize}[leftmargin=*]
  \item estimated timestamps;
  \item a wrong literature claim about resizing position embeddings;
  \item a hung SSH probe;
  \item a shared-filesystem race;
  \item the pre-registration parse slip;
  \item \code{TRAIN.LAMBDA 0} instead of \code{0.0}.
\end{itemize}

\paragraph{Integrity.} No other student's repository was opened or used. The files the guide references but upstream lacks were written from the guide's documented interface.
